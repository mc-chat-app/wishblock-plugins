# /sethome and /home

> **Typed into Wishblock:** *Add /sethome and /home commands*

- `/sethome` saves the spot you are standing on as your home.
- `/home` teleports you back there from anywhere, with portal particles and a whoosh.
- One home per player, kept in the plugin's `config.yml`. Every player can use both.

**Download:** [the jar](https://github.com/mc-chat-app/wishblock-plugins/releases/tag/sethome-home-v1). It needs nothing but Paper 26.2; drop it in `plugins/` and restart.
It was loaded on a stock Paper 26.2 server (build 134) before it was published here.

**[Make your own version](https://app.wishblock.net/?wish=Add%20/sethome%20and%20/home%20commands&ref=github)**: opens Wishblock with this sentence already typed, so you can change it ("let ops open other players' ender chests"). Free, no download.

The code in this folder is what Wishblock's AI wrote for that sentence, as it was built and tested. See the [main page](../) for how it was made.
