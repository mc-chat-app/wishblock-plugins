# /invsee: look at another player's inventory

> **Typed into Wishblock:** *Make a /invsee command to look at another player's inventory*

- `/invsee <player>` opens a window with that player's whole inventory: hotbar, armour and off hand.
- Items can be taken out or put in, and it changes their real inventory.
- Ops only (`invsee.use`, default op).

**Download:** [the jar](https://github.com/mc-chat-app/wishblock-plugins/releases/tag/invsee-v1). It needs nothing but Paper 26.2; drop it in `plugins/` and restart.
It was loaded on a stock Paper 26.2 server (build 134) before it was published here.

**[Make your own version](https://app.wishblock.net/?wish=Make%20a%20/invsee%20command%20to%20look%20at%20another%20player%27s%20inventory&ref=github)**: opens Wishblock with this sentence already typed, so you can change it ("let ops open other players' ender chests"). Free, no download.

The code in this folder is what Wishblock's AI wrote for that sentence, as it was built and tested. See the [main page](../) for how it was made.
