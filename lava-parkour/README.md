# Lava Parkour for Minecraft

> **Typed into Wishblock:** *Make a lava parkour where the platforms melt after you jump*

- `/lavaparkour` builds a lava pool with stone stepping platforms and a gold finish in front of you.
- Each platform glows hot and melts into lava after you jump off it, so there is no going back.
- Falling in sends you back to the start without hurting you. Reaching the gold wins.

**Download:** the jar is on the [Releases](../../releases) page. It needs nothing but Paper 26.2; drop it in `plugins/` and restart.
It was loaded on a stock Paper 26.2 server (build 134) before it was published here.

**[Make this on your own server](https://app.wishblock.net/?wish=Make%20a%20lava%20parkour%20where%20the%20platforms%20melt%20after%20you%20jump&ref=github)**: opens Wishblock with this sentence already typed. Free, no download.

The code in this folder is what Wishblock's AI wrote for that sentence, as it was built and tested. See the [main page](../) for how it was made.
